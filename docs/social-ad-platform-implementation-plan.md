# 社交广告平台项目实现清单计划

## 1. 项目目标

本项目目标是实现一个基于 **NestJS + MySQL + Vue3/Vite + HBuilder/uni-app** 的社交广告平台。平台支持用户登录、手机号入库、图片上传、发布图文动态、点赞评论、公告置顶、广告展示、广告付费购买、后台审核与统一管理。

## 2. 技术架构清单

### 2.1 后端服务

- 使用 NestJS 作为后端框架。
- 使用 MySQL 作为业务数据库。
- 使用 TypeScript 作为主要开发语言。
- 使用 JWT 实现用户端和管理后台鉴权。
- 使用 TypeORM 或 Prisma 管理数据库模型与迁移。
- 使用 Swagger 输出接口文档。
- 使用本地上传作为开发阶段文件存储方案。
- 预留阿里云 OSS、腾讯云 COS 或七牛云等对象存储扩展能力。
- 预留微信支付 JSAPI 支付能力。
- 预留微信小程序登录和手机号授权能力。

### 2.2 管理后台

- 使用 Vue3 作为前端框架。
- 使用 Vite 作为构建工具。
- 使用 TypeScript 提升代码可维护性。
- 使用 Element Plus 作为管理后台 UI 组件库。
- 使用 Pinia 管理前端状态。
- 使用 Vue Router 管理页面路由。
- 使用 Axios 统一封装接口请求。
- 可选使用 ECharts 展示统计图表。

### 2.3 小程序端

- 使用 HBuilderX / uni-app 架构。
- 使用 Vue3 语法开发小程序页面。
- 优先适配微信小程序。
- 支持首页信息流、发布动态、动态详情、个人中心、广告购买、广告订单等页面。
- 使用 uni.uploadFile 对接图片上传接口。
- 使用 uni.requestPayment 对接微信支付。

## 5. 数据库表实现清单

### 5.1 基础表

- users：用户表，包含 openid、unionid、昵称、头像、手机号、手机号验证状态、状态、最近登录时间。
- admins：管理员表，包含账号、密码、昵称、角色、状态。
- files：文件表，记录上传文件地址、路径、文件名、大小、类型、存储方式和使用场景。

### 5.2 社交内容表

- posts：动态表，包含用户、内容、图片 JSON、置顶、推荐、状态、点赞数、评论数、浏览数。
- post_likes：动态点赞表，包含动态 ID、用户 ID，并对 post_id + user_id 设置唯一约束。
- comments：评论表，包含动态 ID、用户 ID、父评论 ID、内容和状态。

### 5.3 运营配置表

- announcements：公告表，包含标题、内容、位置、置顶、状态、开始时间、结束时间和排序。
- ad_positions：广告位表，包含名称、编码、尺寸、最大展示数、每日价格、状态和排序。
- ad_packages：广告套餐表，包含广告位、套餐名称、天数、价格、原价、状态和排序。

### 5.4 广告交易表

- ad_orders：广告订单表，包含订单号、用户、广告位、套餐、金额、支付状态、订单状态、支付时间、投放时间和拒绝原因。
- ads：广告内容表，包含订单、用户、标题、图片、广告位、跳转类型、跳转地址、状态、投放时间、曝光数、点击数和拒绝原因。
- ad_logs：广告日志表，记录曝光和点击事件，后续用于广告效果统计。

- 未登录用户可浏览公开内容，发布、点赞、评论、购买广告前必须登录。

- 手机号需要入库，广告购买前建议强制授权或绑定手机号。
- 广告支付成功后不直接展示，必须等待后台审核。
- 审核拒绝时展示拒绝原因。

## 8. 主要接口实现清单

### 8.1 用户端接口

- POST /api/auth/wx-login：微信登录。
- POST /api/auth/wx-phone：微信手机号授权入库。
- GET /api/user/profile：获取当前用户资料。
- PATCH /api/user/profile：更新当前用户资料。
- POST /api/upload/image：上传单张图片。
- POST /api/upload/images：上传多张图片。
- GET /api/posts：获取动态列表。
- POST /api/posts：发布动态。
- GET /api/posts/:id：获取动态详情。
- POST /api/posts/:id/like：点赞或取消点赞。
- GET /api/posts/:id/comments：获取评论列表。
- POST /api/posts/:id/comments：发布评论。
- DELETE /api/comments/:id：删除自己的评论。
- GET /api/announcements：获取公告。
- GET /api/ads：按广告位获取广告。
- POST /api/ads/:id/view：记录广告曝光。
- POST /api/ads/:id/click：记录广告点击。
- GET /api/ad-positions：获取广告位列表。
- GET /api/ad-packages：获取广告套餐列表。
- POST /api/ad-orders：创建广告订单。
- GET /api/my/ad-orders：获取我的广告订单。
- GET /api/my/ad-orders/:id：获取我的广告订单详情。

### 8.2 支付接口

- POST /api/pay/wechat/prepay：创建微信预支付订单。
- POST /api/pay/wechat/notify：微信支付回调。

### 8.3 管理后台接口

- POST /api/admin/auth/login：管理员登录。

- GET /api/admin/users：用户列表。

- GET /api/admin/comments：评论列表。

- GET /api/admin/files：文件列表。

- GET /api/admin/announcements：公告列表。

## 11. 风险与注意事项

- 社交内容必须考虑审核、举报、删除、封禁等合规能力。
- 小程序涉及用户内容发布和广告展示时，需要准备用户协议和隐私政策。
- 手机号入库必须注意隐私合规，不能明文暴露给无权限人员。
- 图片上传必须限制类型和大小，避免恶意上传。
- 广告必须审核后展示，避免违规广告直接上线。
- 微信支付回调必须验签，并做好幂等处理。
- 广告订单状态和广告内容状态要分开管理，避免支付、审核、投放逻辑混乱。
- 正式上线建议使用对象存储，不建议长期使用服务器本地磁盘保存图片。

## 13. 推荐验收标准

### 13.1 用户端验收

- 用户可以完成微信登录。
- 用户手机号可以成功入库。
- 用户可以上传图片。
- 用户可以发布带图片的动态。
- 用户可以浏览动态列表和详情。
- 用户可以点赞和取消点赞。
- 用户可以发表评论。
- 用户可以查看公告和广告。
- 用户可以购买广告套餐并生成订单。
- 用户可以完成支付并看到订单状态。

### 13.2 后台验收

- 管理员可以登录后台。
- 管理员可以查看和禁用用户。
- 管理员可以查看、隐藏、删除和置顶动态。
- 管理员可以查看和删除评论。
- 管理员可以管理公告。
- 管理员可以管理广告位。
- 管理员可以管理广告套餐。
- 管理员可以查看广告订单。
- 管理员可以审核通过或拒绝广告。
- 管理员可以查看基础统计数据。

### 13.3 广告业务验收

- 广告位可以配置价格和状态。
- 广告套餐可以按广告位配置。
- 用户购买广告时可以上传广告图片。
- 用户支付成功后广告进入待审核状态。
- 审核通过后广告在指定时间和位置展示。
- 审核拒绝后用户可以看到拒绝原因。
- 广告到期后自动停止展示。
- 广告曝光和点击可以被记录。
